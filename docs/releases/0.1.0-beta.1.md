# FerriteDB 0.1.0-beta.1

FerriteDB's first public beta provides a one-command Node.js installation for Linux x86_64, an exact-version managed sidecar, versioned database format, crash-tested WAL/checkpoint boundaries, and a backup-first alpha migration path.

## Install

```bash
npm install @ferritedb/sdk@beta
```

```ts
import { FerriteDB } from "@ferritedb/sdk";

const db = await FerriteDB.open("./app-db");
await db.put("settings/theme", { dark: true });
await db.close();
```

## Upgrade from alpha

Alpha databases are not opened implicitly:

```bash
ferrite migrate ./alpha-db ./beta-db --backup ./alpha-db-backup
```

The destination and backup must be distinct siblings of the alpha database.

## Important limitations

This is an unaudited beta for Linux x86_64 and Node.js. Do not use it for production, security-critical workloads, or irreplaceable data. Physical power-cut behavior has not been tested. See `README.md`, `docs/FORMAT.md`, and `docs/THREAT_MODEL.md` before adopting it.
